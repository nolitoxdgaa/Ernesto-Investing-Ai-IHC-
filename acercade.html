Resultado de Aprendizaje: RA4 (CT10.2, CT13.2) — Propone mejoras en el diseño de interfaces hombre-computador considerando localización, internacionalización, metáforas y modelos conceptuales.

Versión 2.0 Internacionalizada (Semana 13 · IHC 2026-II)

Arquitectura en 3 Zonas de i18n

  • Zona 1 (Núcleo independiente): Lógica de pronóstico, matrices de covarianza, optimizador Markowitz y backtesting sin textos visibles fijos.
  • Zona 2 (Recursos externalizados): Diccionarios JSON por locale BCP 47 (es-PE, en-US, ar-EG, ja-JP, qu-PE) y formateadores con API Intl.
  • Zona 3 (Adaptación cultural): Selector de idioma por endónimos, dirección RTL automática, CSS lógico, selector de zonas horarias y pseudolocalización.

Stack Tecnológico

  • Frontend: HTML5 semántico, CSS3 lógico, Vanilla JavaScript modular.
  • Visualización: Apache ECharts 5.5.1 + Micro-gráficos Sparkline SVG nativos.
  • Internacionalización: API estándar ECMAScript Intl (NumberFormat, DateTimeFormat, PluralRules, Collator).
  • Almacenamiento: 13 fuentes de datos JSON estáticos + localStorage para estado de sesión.

Declaración de Veracidad y Ética (G.10 / L.12)

Todos los precios, pronósticos y rentabilidades son estrictamente sintéticos con fines pedagógicos. No constituye asesoría financiera.

  • Los precios y portafolios son sintéticos; solo volatilidad, beta y correlación se anclan a datos históricos reales.
  • Las cantidades y divisas se conservan sin conversión ficticia al alternar de idioma.
  • Las traducciones al árabe, japonés y quechua son borradores preliminares que requieren revisión de hablantes nativos competentes.
  • Se declara el uso de Inteligencia Artificial como asistente técnico, con verificación manual de código y trazabilidad íntegra.
